Editor máp 2

O Editore

Editor máp je aplikácia, ktorá umožňuje úpravou preddefinovaných máp vytvoriť si vlastné mapy. Vytvorenú mapu je možné uložiť na disk, opätovne načítať, ďalej upravovať, vytlačiť, prípadne exportovať. Obsahuje tiež niekoľko aktivít na preskúšanie si zemepisných vedomostí.

Vo verzii 2 program obsahuje tieto mapy:

  • Slovensko
  • Afrika
  • Austrália
  • Ázia
  • Európa
  • Južná Amerika
  • Severná Amerika
  • svet

S každou mapu je možné:

  • nastavovať viditeľnosť objektov mapy (napr. štátov, pohorí, riek atd.) a ich farebnosť
  • nastavovať viditeľnosť a polohu značiek/popisiek objektov a editovať text popisiek
  • pridávať vlastné značky
  • kresliť do mapy základné geometrické tvary
  • exportovať celú mapu alebo jej časť ako PNG alebo JPEG obrázok
  • tlačiť celú mapu alebo jej časť

Program obsahuje aj tri zábavné aktivity:

  • Vyskúšaj sa - z viacerých ponúknutých objektov je potrebné vždy vybrať ten správny
  • Traf sa - je potrebné trafiť zameriavačom čo najbližšie správnej polohe určeného mesta
  • Poskladaj - ťahaním štátov myšou je potrebné ich uložiť čo najpresnejšie kam patria

Aplikácia Editor máp v.2 bola vytvorená s podporou projektu "Modernizácia vzdelávacieho procesu na základných školách" a "Modernizácia vzdelávacieho procesu na stredných školách" spolufinancovaných zo zdrojov ES. Projekty patria pod operačný program Vzdelávanie, prioritná os 1: Reforma systému vzdelávania a odbornej prípravy a opatrenie 1.1: Premena tradičnej školy na modernú.

Ďalšie informácie je možné získať na web stránke www.oslovensku.sk.

Technické požiadavky

Program je určený pre platformu Adobe® Air® vo verzii 1.5 pre operačný systém Windows (vo verzii min. Windows 2000 SP4, Windows 2003 Server, Windows XP SP2, Windows Vista® SP1 a Windows 7). Obmedzene funguje aj v operačných systémoch MAC OS X (verzia 10.4.11 a vyššie) a Linux (vo verzii min. Fedora 8, Ubuntu 7.10, OpenSuse 10.3) s xterm.

Minimálne doporučené rozlíšenie displeja je 1024x768px.
